A negamax alpha-beta chess engine in 3,894 bytes of Python. 0x88 board, full legal move generation, transposition table, quiescence search, fixed 50,000-node budget per move. Mean practice Elo 1453 against the house gauntlet.

## Run it

```sh
MAKEFUN_ENV_URL=<env-url> python3 main.py
```
